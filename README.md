# IPOSTEL_MOVIL
Sistema de control, monitoreo y reporte de movilidad diaria de despachos (Masters) para IPOSTEL.

## Arquitectura
- **Frontend:** HTML5, Bootstrap 5, SweetAlert2 (Alojado en GitHub Pages).
- **Backend:** Google Apps Script (Web App).
- **Base de Datos:** Google Sheets.

## Roles del Sistema
- **Encaminamiento:** Crea Masters, valida pesos, emite reportes.
- **Gerente de Estado:** Carga envíos locales con foto.
- **Seguimiento y Control:** Registra hitos de tracking.
- **Coordinador CNC:** Valida seguimiento y carga cobros.
- **Observatorio / Presidencia:** Visualización y configuración.

## Tiempos de Entrega (SLA)
El semáforo se calcula en base a las horas de tránsito establecidas por región (Centro, Occidente, Llanos, Andes, Oriente).
